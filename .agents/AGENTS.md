# Browser Preference Rules

- **Browser Verification**: Whenever you need to preview the website, open a URL, or run a check through a browser on the local machine, always use Brave Browser.
- **Do Not Use Chrome**: Google Chrome is not installed on this system.
- **Local Commands**: If launching the browser via command line, use the `brave` CLI, open `brave.exe` from its standard installation paths, or use default system commands (like `Start-Process` or `explorer` with the URL) which respect the user's default browser (Brave).
